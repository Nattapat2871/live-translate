# Live Translate — แปลเสียงเพื่อนต่างชาติแบบเรียลไทม์

ซับแปลภาษาสำหรับเกมเมอร์: ฟังเสียงเพื่อนจาก Discord หรือวอยซ์ในเกม (เสียงในคอม) หรือจากไมค์ แล้วแสดงคำแปลบนป้ายแบบ Arrivals ของสนามบิน บรรทัดใหม่สุดอยู่บนสุดและตัวใหญ่สุด เปิดเป็นหน้าต่างซับลอยทับเกมได้
**ใช้ฟรี ไม่ต้องสมัคร ไม่ต้องใส่ key และไม่มีเซิร์ฟเวอร์**

**เปิดใช้งาน:** https://nattapat2871.me/live-translate/

## วิธีใช้

1. เปิดด้วย **Chrome หรือ Edge** บนคอม
2. เลือก **เสียงในคอม** แล้วเลือกภาษาที่เพื่อนพูด และภาษาที่จะแปลเป็น
3. กด **เริ่มฟัง** → เลือก **ทั้งหน้าจอ** (หรือแท็บ Discord บนเว็บ) → ติ๊ก **แชร์เสียงของระบบ** → แชร์
4. กด **ซับลอย** ให้คำแปลลอยอยู่บนเกม (เกมต้องเป็นโหมด Borderless หรือ Windowed)

## ตัวแปล (เลือกได้ใน ตั้งค่า)

| ตัวแปล | ต้องใส่อะไร | ทำงานยังไง |
|---|---|---|
| Google (ค่าเริ่มต้น) | ไม่ต้อง | แปลทันทีทุกประโยค และแนบประโยคก่อนหน้าไปเป็นบริบท |
| Chrome AI | ไม่ต้อง (ดาวน์โหลดโมเดลครั้งแรก) | Google แปลก่อน แล้ว AI ในเครื่องเกลาให้เข้าบริบท ข้อความไม่ออกจากเครื่อง ภาษาที่รองรับขึ้นกับเบราว์เซอร์ |
| Claude | API key **ของคุณเอง** | Google แปลก่อน แล้ว Claude เกลาโดยอ่านบทสนทนาล่าสุด เข้าใจศัพท์เกม |

ข้อมูลเรื่อง API key:
- เว็บนี้ไม่มี key ของตัวเองและไม่มีเซิร์ฟเวอร์
- key ของคุณเก็บในเบราว์เซอร์ของคุณเท่านั้น (ค่าเริ่มต้นคือ `sessionStorage` ปิดแท็บแล้วลืม หรือเปิดสวิตช์ "จำ key" ได้) และส่งตรงไปที่ `api.anthropic.com`
- ระบบรับเฉพาะค่าที่ขึ้นต้นด้วย `sk-ant-` ถ้าเบราว์เซอร์เติมรหัสผ่านลงช่องนี้เอง ค่านั้นจะไม่ถูกเก็บและไม่ถูกส่งไปไหน

## รับมือกับคนที่พูดเร็ว พูดไม่หยุด หรือพูดพร้อมกัน

- **คำแปลระหว่างพูด:** แปลซ้ำได้ทุก ~0.4 วินาที โดยมีคำขอค้างอยู่ได้ทีละคำขอเท่านั้น ถ้าตัวแปลตอบช้ากว่าคนพูด คำแปลก็ยังอัปเดตตามได้
- **พูดยาวไม่หยุด:** ตัดเป็นแถวเองเมื่อยาวเกิน ~14 คำ (หรือ 40 ตัวอักษรสำหรับภาษาที่ไม่เว้นวรรค เช่น ไทย ญี่ปุ่น จีน) หรือเกิน 4 วินาที ไม่ต้องรอให้หยุดพูด
- **ส่งคำขอพร้อมกันได้จำกัด:** Google 3 คำขอ AI 2 คำขอ ถ้า AI ตามไม่ทัน จะข้ามบรรทัดเก่าแล้วเกลาบรรทัดใหม่สุดก่อน ถ้า Google ตอบ 429 จะลองใหม่ให้ 1 ครั้ง
- **เมื่อ Chrome ตัดการฟัง (หลังเงียบ หรือทุก ~1 นาที):** เริ่มฟังรอบใหม่ทันที เก็บข้อความที่ค้างไว้ และลองเชื่อมต่อใหม่เองเมื่อเน็ตหลุด
- **ข้อจำกัด:** ถ้าหลายคนพูดพร้อมกัน ระบบแยกเสียงแต่ละคนไม่ได้ ข้อความอาจปนกัน ตัวแปลแบบ AI จะพยายามแยกเป็นท่อนๆ ให้

## พัฒนา

```bash
npm install
npm run dev      # http://localhost:5173/live-translate/
npm test         # stress tests ของ pipeline (พูดรัว พูดซ้อน 429 AI ช้า ผลกลับมาสลับลำดับ)
npm run build
```

Stack: React 19 · HeroUI v2 · Tailwind CSS v4 · Vite · Web Speech API · Document Picture-in-Picture
Deploy: push ขึ้น `main` แล้ว GitHub Actions จะ build และขึ้น GitHub Pages ให้เอง
