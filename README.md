# 🎧 Live Translate — แปลเสียงเพื่อนต่างชาติแบบเรียลไทม์

เว็บแปลเสียงสำหรับเกมเมอร์: ฟังเสียงเพื่อนจาก Discord / เกม (เสียงในคอม) หรือไมค์ แล้วขึ้นซับแปลภาษาทันที
มีหน้าต่างซับลอยทับเกมได้ ไม่มีหลังบ้าน — เป็นไฟล์ HTML ไฟล์เดียว

**เปิดใช้งาน:** https://nattapat2871.github.io/live-translate/

## วิธีใช้

1. เปิดด้วย **Chrome หรือ Edge** (รุ่นใหม่)
2. เลือก **🖥️ เสียงในคอม** และภาษาที่เพื่อนพูด
3. กด **▶ เริ่ม** → เลือก **ทั้งหน้าจอ** (หรือแท็บ Discord บนเว็บ) → ติ๊ก **แชร์เสียงของระบบ** → แชร์
4. กด **📌 ลอยทับเกม** ให้ซับลอยอยู่บนเกม (เกมต้องเป็นโหมด Borderless / Windowed)

## การแปล

| โหมด | ใช้อะไร | จุดเด่น |
|---|---|---|
| ฟรี (ค่าเริ่มต้น) | Google Translate + แนบประโยคก่อนหน้าเป็นบริบท | ไม่ต้องตั้งค่า |
| AI (ใส่ Claude API key ใน ⚙️) | Claude แปลโดยดูบทสนทนาล่าสุด | เข้าใจศัพท์เกม สรรพนาม และแก้คำที่ถอดเสียงผิด |

ในโหมด AI คำแปล Google จะขึ้นก่อนทันที แล้ว Claude แทนที่ตามมา (มีเครื่องหมาย ✨)
API key เก็บใน `localStorage` ของเบราว์เซอร์คุณเท่านั้น และส่งตรงไป `api.anthropic.com`

## ทำงานยังไง

```
เสียงในคอม (getDisplayMedia) / ไมค์ (getUserMedia)
  → MediaStreamTrack → SpeechRecognition.start(track)  [ถอดเสียงโดย Chrome]
  → ข้อความระหว่างพูด (interim) → Google แปลสด
  → ประโยคจบ (final) → Google + Claude (มีบริบท) → ซับ + หน้าต่างลอย (Document Picture-in-Picture)
```

## ข้อจำกัด

- ใช้ได้เฉพาะ Chrome / Edge (Web Speech API)
- เกมที่เป็น Exclusive Fullscreen จะบังหน้าต่างลอย
- แยกเสียงผู้พูดหลายคนไม่ได้
